# Import Tuner Challenge Static Recompilation

This is a test run of using AI for this kind of thing. Don't expect perfection, but it does run.

## Install

Extract the game files from a backup, then drop the files in the zip into that folder (where the xex is). Use run.sh to play. Frame interpolation (experimental, races only) is on by default; `./run.sh --no-interpolation` plays at the original 30 fps. Use `./run-debug.sh` if logging is required.
