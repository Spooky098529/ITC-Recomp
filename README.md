# Import Tuner Challenge Static Recompilation

This was a test run of using AI for this kind of thing. Don't expect perfection, but it does run.

## Install

Extract the game files from a backup, then drop the files in the zip into that folder (where the xex is). Use run.sh to play. Frame interpolation (experimental, races only) is on by default; `./run.sh --no-interpolation` plays at the original 30 fps. `run.sh` writes no logs; to report a problem, play with `./run-debug.sh` instead and attach the newest file from the `logs` folder.
